# M43Y: retrospective native response and component diagnosis

Publicly freeze this plan, code and explicit probe/input inventory before evaluation.
This is development evidence selected from exposed M43X failures, not independent
confirmation. No detector, threshold, mask, width matching, physical veto, rank,
or confirmation rule is changed. Preserve all M43X losses and failed adoption gates.

## Scope and denominators

Exactly 13 base executions, each with the three unchanged X post-cut policies:
1 uninjected baseline; exact original controls 13,45,47,79,109,111; and ON-only
and OFF-only counterparts of ON-OFF cases 47,79,111. Six originals and baseline
must exactly replay historical X compact audits and all policy decisions.
The six new component inputs change only which declared native components are
present, retaining original order, strengths, coordinates, normalization and data.
Cases 13/45/109 have identical native patch inventories despite different labels.
Publish every label and group actual patch identities; do not count them as
independent waveforms. Reuse one observing sequence, with no new telescope request.

Replay X training shifts under its exact window identity and verify the complete
calibration summary, 128 maxima, threshold and binding against X. No fresh null
rows, heldout claim or new physical false-alarm estimate. Existing 1,536 used
shift rows remain excluded from any future fresh panel. Verify all 96 original
arrays and all 48 native gathers before intervention. Do not rerun the full X panel.

## Fixed measurements

Freeze the union of all remaining-aggregate surviving member coordinates in the
six controls, together with each ON-OFF injection center on its declared template
and activity. Measure this same inventory in all 13 inputs, including baseline.
No response-dependent probe selection. For both ON and OFF, all three epochs and
all widths 1,3,5,9,17,33,65,129, record inclusive proxy-coordinate neighborhoods
q +/- floor(width/2), using full guard support without clipping. Record all values,
center, maximum, first maximum coordinate and existing neighbor9 mask. A broad
filter response interval is a diagnostic interval, not a validated veto tolerance.

At every probe/width/kind/epoch independently rebuild raw native windows, apply
ordered float32 point additions, filter and integrate rows, and demand exact
float32 equality to detector score vectors. All selected components are snapped
point profiles; reject unsupported profiles. Preserve native row indices and values.
Reuse existing native arithmetic validation; three focused tests cover inclusive
boundaries/ties, incomplete coverage and point-addition row normalization.

Preserve existing mask seed traces, paired OFF measurements, retained-OFF track
witnesses, receiver signatures/alias decisions and rank evidence for each probe;
retain the full OFF ledger. An absent retained probe is explicit. Counterpart
comparisons use fixed coordinates, not only changing final-member counts.

## Interpretation and completion

Publish exact replay/anchor checks, sealed case ledger, native identity groups,
paired component differences and an independently recomputed artifact audit.
Separate measured stage outcomes from mechanistic interpretation. In particular,
zero exact-coordinate OFF veto need not mean no OFF response elsewhere. A retained
OFF track match and a same-coordinate single-OFF query have different semantics.
Neighboring OFF maxima do not prove a safe replacement rule or its false-veto cost.

If data or replay validation fails, preserve the failure and repair only a
demonstrated implementation issue; publish an amendment before changing evaluation
semantics. Never tune the 5.5 floor or adopt a rule on these selected controls.
The follow-on decision must identify what new response-matching endpoint and
signal/control/false-veto evidence would be necessary, while retaining the
unresolved two-epoch sensitivity cost of M43X.
