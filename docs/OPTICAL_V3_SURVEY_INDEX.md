# Pankromatisk `V3.0–V3.3`-survey (`D079–D082`): Prospektivt kalibreret 4-kanals optisk & nær-IR lasersøgning på `80` nære FGKM- og exoplanet-stjerner (`501` eksponeringer, `0,38–1,80 µm`)

Dette dokument indekserer projektets 3. generations optiske og nær-infrarøde echelle-SETI-spor (`HARPS_ECELLE_V3`, `ECELLE_V3_1`, `ECELLE_V3_2` og `NIRPS_V3_3`), iværksat efter lukningen af `HD 43629`-forløbet (`D001`–`D078`, se [`OPTICAL_HD43629_INDEX.md`](OPTICAL_HD43629_INDEX.md)) og sammenskrevet i publikationsmanuskriptet [`paper/ANDERSEN_2026_PANCHROMATIC_ECHELLE_SETI_SURVEY.md`](../paper/ANDERSEN_2026_PANCHROMATIC_ECHELLE_SETI_SURVEY.md) ([`paper/main.tex`](../paper/main.tex)).

> **Samlet status over `D079 + D080 + D081 + D082` (15. november 2026):** **`0` verificerede ETI-lasersignaler** på tværs af **`501` højopløste echelle-eksponeringer af `80` unikke FGKM-stjerner** (`220` ESO `HARPS` + `129` VLT `ESPRESSO` + `152` ESO `NIRPS_HE`; `66` science-stjerner inkl. `56` exoplanet-systemer med `118` bekræftede planeter og **`29` stjerner inden for `10,0 pc`** + `14` dedikerede nul-planet kontrolstjerner; `6.570` syntetiske kalibreringsforsøg; `5.850` `Legacy V2` falske alarmer elimineret til `0` kontrol-falskalarmer). Kalibrerede `8σ`-øvre grænser for en diffraktionsbegrænset `10 m`-sender når ned til **`9,0 W`** optisk og **`607,7 W` ved `1064,1 nm` (`Nd:YAG`/`Yb`)** / **`1.026,1 W` ved `1550,0 nm` (`Er` C-bånd)** på `Proxima Centauri` ($d = 1,302$ pc), med en median bedste pankromatisk grænse på **`1,75 kW`** over `23` exoplanet-værter inden for `10 pc`.
