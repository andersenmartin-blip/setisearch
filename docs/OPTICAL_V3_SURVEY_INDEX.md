# Rum-Lyman til JWST Termisk-IR + ESO 3-Arm + All-Sky Pankromatisk `V3.0–V4.2` + `COMB_V4_1`-survey (`D079–D091`): Prospektivt kalibreret lasersøgning på `310` unikke stjernesystemer (`2.076` eksponeringer, `0,0905–28,00 µm`, `8,273` oktaver) + `23/23` Radio-Echelle Lukning

Dette dokument indekserer projektets 3.–4. generations rum-Lyman, FUV, NUV, optiske, fjernrøde, nær-infrarøde, **ESO triple-3arm (`VLT X-shooter`, `MPG/ESO FEROS`, `VLT FLAMES/GIRAFFE`)** og **JWST termisk-IR (`NIRSpec G235H`, `NIRSpec G395H`, `MIRI MRS Ch1–4`)** SETI-spor (`D079–D091`: `HARPS_ECELLE_V3`, `ECELLE_V3_1`, `ECELLE_V3_2`, `NIRPS_V3_3`, `CRIRES_V3_4`, `NORTHERN_V3_5`, `SPIROU_V3_6_AND_COMB_V4`, `PANCHROM_NUV_OPT_V3_7_AND_COMB_V4_1`, `SPACE_UV_STIS_AND_FARRED_V3_8`, `NORTHERN_RADIO23_AND_ALLSKY_COMB_V4_1_V3_9`, `SPACE_LYMAN_FUV_NUV_V4_0`, `JWST_SPACE_THERMAL_IR_V4_1` og **`ESO_TRIPLE_SPECTROGRAPH_3ARM_V4_2`**), iværksat efter lukningen af `HD 43629`-forløbet (`D001`–`D078`, se [`OPTICAL_HD43629_INDEX.md`](OPTICAL_HD43629_INDEX.md)) og sammenskrevet i publikationsartiklen [`paper/ANDERSEN_2026_PANCHROMATIC_ECHELLE_SETI_SURVEY.pdf`](../paper/ANDERSEN_2026_PANCHROMATIC_ECHELLE_SETI_SURVEY.pdf) ([`ANDERSEN_2026_PANCHROMATIC_ECHELLE_SETI_SURVEY.md`](../paper/ANDERSEN_2026_PANCHROMATIC_ECHELLE_SETI_SURVEY.md) · [`paper/main.tex`](../paper/main.tex)).

> **Samlet status over `D079–D091` (20. november 2026):** **`0` verificerede ETI-lasersignaler eller frekvenskamme** på tværs af **`2.076` spektroskopiske eksponeringer (`634,3886 timer`) af `310` unikke stjernesystemer** på **`19` spektrografer (`22` arme) over `8,273` ubrudte oktaver (`0,0905–28,00 µm`)** (`36` `FUSE_FUV` + `84` `HST_COS G130M` + `54` `HST_STIS E140M` + `72` `HST_STIS NUV E230M/E230H` + **`33` `ESO_XSHOOTER_3ARM`** + `55` `UVES_NUV` + **`36` `ESO_FEROS`** + `298` `HARPS` + `269` `ESPRESSO` [`HR/UHR`] + `55` `UVES_RED` + `68` `OHP_SOPHIE` + `48` `OHP_ELODIE` + `60` `CFHT_ESPADONS` + `64` `HARPS-N` + **`87` `ESO_GIRAFFE_HR`** + `119` `CARMENES_VIS` + `152` `NIRPS_HE` + `177` `CFHT SPIRou` + `148` `VLT CRIRES+` + `33` `JWST_NIRSPEC_G235H` + `63` `JWST_NIRSPEC_G395H` + `65` `JWST_MIRI_MRS`; `239` science-stjerner inkl. `154` exoplanet-værter med `304` planeter og **`135` stjerner inden for `10,0 pc`** [`100` science med `110` planeter på `53` værter + `35` kontroller] + `71` nul-planet kontrolstjerner; `29.466` syntetiske kalibreringsforsøg; `286.043` `Legacy V2` falske alarmer elimineret på tværs af `100` orbitale kampagner; samt **uniform all-sky `COMB_V4_1`-sweep på samtlige `358` stacks / `2.076` eksponeringer** [`16.037 -> 45 -> 0 ETI`]). Kalibrerede `8σ`-øvre grænser for en `10 m`-sender når ned til **`0,0973 W`** (`Proxima Centauri` `HST_STIS`), **`0,2194 W`** (`GJ 832` `HST_COS`), **`0,4294 W`** (`Alpha Cen A` `FUSE`), **`0,800 W`** (`Proxima Cen` `UVES_NUV`), **`0,33023 kW`** (`VLT X-shooter LAWD37`), **`1,00596 kW`** (`GIRAFFE_HR OGLETR113`), **`228,98 W` (`0,228981 kW`)** (`WISE0855` `JWST_MIRI_MRS` `5,80 µm`) og **`2,70465 kW`** (`VMA2` ved Townes (1983) `10,60 µm` $\mathrm{CO_2}$-laser), med en median grænse på **`1,62371 kW`** over `< 10 pc` og **`35` pankromatiske brostjerner (`625` celler)**. Forenet med `23` `Parkes`/`GBT` `1,4 GHz` radiomål og `TESS` (`L 98-59`) opnår surveyet **`23/23` (`100 %`) radio-echelle lukning** (`24` direkte overlaps inkl. **to tri-regime systemer: `16CYGB` Radio + Optisk + MIRI og `GJ849` Radio + IR + X-shooter**) på tværs af **`310` distinkte stjernesystemer** med **`0` verificerede ETI-detektioner**.
