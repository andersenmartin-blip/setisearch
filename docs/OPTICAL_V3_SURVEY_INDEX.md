# Optisk `V3.0–V3.2`-survey (`D079–D081`): Prospektivt kalibreret 4-kanals lasersøgning på `60` nære FGKM- og exoplanet-stjerner (`349` eksponeringer)

Dette dokument indekserer projektets 3. generations optiske echelle-SETI-spor (`HARPS_ECELLE_V3`, `ECELLE_V3_1` og 4-kanals `ECELLE_V3_2`), iværksat efter lukningen af `HD 43629`-forløbet (`D001`–`D078`, se [`OPTICAL_HD43629_INDEX.md`](OPTICAL_HD43629_INDEX.md)).

> **Samlet status over `D079 + D080 + D081` (15. november 2026):** **`0` verificerede ETI-lasersignaler** på tværs af **`349` friske højopløste echelle-eksponeringer af `60` unikke FGKM-stjerner** (`220` ESO `HARPS` + `129` VLT `ESPRESSO`; `50` science-stjerner inkl. `40` exoplanet-systemer med `85` planeter og `18` stjerner inden for `10,0 pc` + `10` dedikerede ikke-planet kontrolstjerner; `4.539` syntetiske kalibreringsforsøg; `0` overlap mod alle tidligere faser). Kalibrerede `8σ`-øvre grænser for en diffraktionsbegrænset `10 m`-sender når helt ned til **`9,0 W` (`0,0090 kW`)** på `Proxima Centauri` ($d = 1,302$ pc).
