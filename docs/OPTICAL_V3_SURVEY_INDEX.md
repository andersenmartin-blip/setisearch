# Rum-Lyman/FUV/NUV + All-Sky Pankromatisk `V3.0–V4.0` + `COMB_V4_1`-survey (`D079–D089`): Prospektivt kalibreret lasersøgning på `250` unikke stjernesystemer (`1.759` eksponeringer, `0,0905–2,515 µm`, `4,796` oktaver) + `23/23` Radio-Echelle Lukning

Dette dokument indekserer projektets 3.–4. generations rum-Lyman, FUV, NUV, optiske, fjernrøde og nær-infrarøde echelle-SETI-spor (`D079–D089`: `HARPS_ECELLE_V3`, `ECELLE_V3_1`, `ECELLE_V3_2`, `NIRPS_V3_3`, `CRIRES_V3_4`, `NORTHERN_V3_5`, `SPIROU_V3_6_AND_COMB_V4`, `PANCHROM_NUV_OPT_V3_7_AND_COMB_V4_1`, `SPACE_UV_STIS_AND_FARRED_V3_8`, `NORTHERN_RADIO23_AND_ALLSKY_COMB_V4_1_V3_9` og **`SPACE_LYMAN_FUV_NUV_V4_0`**), iværksat efter lukningen af `HD 43629`-forløbet (`D001`–`D078`, se [`OPTICAL_HD43629_INDEX.md`](OPTICAL_HD43629_INDEX.md)) og sammenskrevet i publikationsartiklen [`paper/ANDERSEN_2026_PANCHROMATIC_ECHELLE_SETI_SURVEY.pdf`](../paper/ANDERSEN_2026_PANCHROMATIC_ECHELLE_SETI_SURVEY.pdf) ([`ANDERSEN_2026_PANCHROMATIC_ECHELLE_SETI_SURVEY.md`](../paper/ANDERSEN_2026_PANCHROMATIC_ECHELLE_SETI_SURVEY.md) · [`paper/main.tex`](../paper/main.tex)).

> **Samlet status over `D079–D089` (19. november 2026):** **`0` verificerede ETI-lasersignaler eller frekvenskamme** på tværs af **`1.759` højopløste echelle-eksponeringer (`569,36 timer`) af `250` unikke stjernesystemer** på **`14` spektrografer (`16` arme) over `4,796` oktaver (`0,0905–2,515 µm`)** (`36` `FUSE_FUV` + `84` `HST_COS G130M` + `54` `HST_STIS E140M` + `72` `HST_STIS NUV E230M/E230H` + `55` `UVES_NUV` + `298` `HARPS` + `269` `ESPRESSO` [`HR/UHR`] + `55` `UVES_RED` + `68` `OHP_SOPHIE` + `48` `OHP_ELODIE` + `60` `CFHT_ESPADONS` + `64` `HARPS-N` + `119` `CARMENES_VIS` + `152` `NIRPS_HE` + `177` `CFHT SPIRou` + `148` `VLT CRIRES+`; `197` science-stjerner inkl. `139` exoplanet-værter med `277` planeter og **`121` stjerner inden for `10,0 pc`** [`89` science med `107` planeter på `52` værter + `32` kontroller] + `53` nul-planet kontrolstjerner; `24.072` syntetiske kalibreringsforsøg; `257.124` `Legacy V2` falske alarmer elimineret til `0` orbitale kandidater på tværs af `80` kampagner; samt **uniform all-sky `COMB_V4_1`-sweep på samtlige `284` stacks / `1.759` eksponeringer** [`5.434 -> 15 -> 0 ETI`]). Kalibrerede `8σ`-øvre grænser for en `10 m`-sender når ned til **`0,0973 W`** (`Proxima Centauri` `HST_STIS`), **`0,2194 W`** (`GJ 832` `HST_COS`), **`0,4294 W`** (`Alpha Cen A` `FUSE`), **`0,3814 W`** (`GJ 667 C` `HST_COS`), **`0,800 W`** (`Proxima Cen` `UVES_NUV`) og **`0,5181 kW`** (`GJ 625` `OHP_SOPHIE`), med en median grænse på **`1,7494 kW`** over `< 10 pc` og **`26` pankromatiske brostjerner (`485` celler)**. Forenet med `23` `Parkes`/`GBT` `1,4 GHz` radiomål og `TESS` (`L 98-59`) opnår surveyet **`23/23` (`100 %`) radio-echelle lukning** (`24` direkte overlaps) på tværs af **`250` distinkte stjernesystemer** med **`0` verificerede ETI-detektioner**.
