# Rum-Lyman til JWST Termisk-IR + ESO 3-Arm + All-Sky `V5.1` Pankromatisk `V3.0–V5.1` + `COMB_V4_1`-survey (`D079–D093`): Prospektivt kalibreret lasersøgning på `350` unikke stjernesystemer (`2.163` eksponeringer, `0,0905–28,00 µm`, `8,273` oktaver) + `23/23` Radio-Echelle Lukning

Dette dokument indekserer projektets 3.–5.1 generations rum-Lyman, FUV, NUV, optiske, fjernrøde, nær-infrarøde (`NIRPS_HE`, `CRIRES+ Y & K`, `SPIRou`), ESO triple-3arm (`VLT X-shooter`, `MPG/ESO FEROS`, `VLT FLAMES/GIRAFFE`), Gemini `GRACES`, ESO `CORALIE`, CAHA `CARMENES_VIS`, og JWST termisk-IR (`NIRSpec G235H`, `NIRSpec G395H`, `MIRI MRS Ch1–4`) SETI-spor (`D079–D093`: `V3.0–V5.0` samt **`TECHNOSIGNATURE_V5_1_DEDOPPLER_DRIFT_MULTIEVENT_ELLIPSOID_GRACES_CORALIE_CARMENES`**), iværksat efter lukningen af `HD 43629`-forløbet (`D001`–`D078`, se [`OPTICAL_HD43629_INDEX.md`](OPTICAL_HD43629_INDEX.md)) og sammenskrevet i publikationsartiklen [`paper/ANDERSEN_2026_PANCHROMATIC_ECHELLE_SETI_SURVEY.pdf`](../paper/ANDERSEN_2026_PANCHROMATIC_ECHELLE_SETI_SURVEY.pdf) ([`ANDERSEN_2026_PANCHROMATIC_ECHELLE_SETI_SURVEY.md`](../paper/ANDERSEN_2026_PANCHROMATIC_ECHELLE_SETI_SURVEY.md) · [`paper/main.tex`](../paper/main.tex)).

> **Samlet status over `D079–D093 V5.1` (21. november 2026):** **`0` verificerede ETI-lasersignaler, drivhusgasser eller frekvenskamme** på tværs af **`2.163` spektroskopiske eksponeringer (`652,7147 timer`) af `350` unikke stjernesystemer** på **`21` spektrografer (`24` arme) over `8,273` ubrudte oktaver (`0,0905–28,00 µm`)** (`268` science-stjerner inkl. `169` exoplanet-værter med `347` planeter og **`153` stjerner inden for `10,0 pc`** [`111` science med `115` planeter på `56` værter + `42` kontroller] + `82` nul-planet kontrolstjerner; `32.408` syntetiske kalibreringsforsøg; `302.198` `Legacy V2` falske alarmer elimineret på tværs af `117` orbitale kampagner; samt **uniform all-sky `COMB_V4_1`-sweep på samtlige `401` stacks / `2.163` eksponeringer** [`22.694 -> 109 -> 0 ETI`]). I `D093` opnår blind lineær drift-rate de-Doppler (`DRIFT_V51`) `60/60` syntetisk genfinding (`0/60` FA) og flagger `135` empiriske par over `111.520.615` evalueringer (`0` ETI), Gate `G8_V51b` undertrykker retroaktivt `D088` med **`95,0 %` (`20 -> 13 -> 1 -> 0 ETI`)** og halverer `D093` `V5.0` (`8 -> 4 -> 0 ETI`), `JWST NIRSpec G395H` unions-ekskluderet molekylær `CCF` opnår `80/80` (`0/80` confounder-FA, `0/12` kontrolflag på `44` celler, `GJ504 CH4_C2H6 +8,291 sigma -> 0 ETI`), `120/120` agnostisk multi-skala (`3 -> 0 ETI`), og `350`-stjerners 3-event SETI Ellipsoid/`ETZ` giver `10` `ETZ` + `33` `<=180 d` (`0` ETI). Kalibrerede `8σ`-øvre grænser når ned til **`0,0973 W`** (`Proxima Cen` `HST_STIS`), **`0,26757 kW`** (`GJ3512` `CARMENES_VIS`), **`198,04 kW`** (`HD217107` `CORALIE`) og **`205,36 kW`** (`WASP52` `GRACES`), med median **`1,45576 kW`** over `< 10 pc` (`153` stjerner) og **`37` pankromatiske brostjerner (`631` celler)** samt **`23/23` (`100 %`) radio-echelle lukning** (`24` direkte overlaps incl. tri-regime `16CYGB` & `GJ849`).
