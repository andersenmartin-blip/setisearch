# SETI: GitHub opdateret gennem D076

13. november 2026.

GitHubs hovedgren er opdateret til [D076-rapporten](https://github.com/andersenmartin-blip/setisearch/tree/main/progress/2026-11-13-feros-d076) via [PR #36](https://github.com/andersenmartin-blip/setisearch/pull/36) og [PR #37](https://github.com/andersenmartin-blip/setisearch/pull/37). Seneste kontrollerede mergecommit er `c505b9de5d77e647f61530a500e72e0c887e5bf8`. Begge testkørsler bestod, og de publicerede tekstfiler blev kontrolleret mod de forberedte bytes.

D075 er genberegnet fra det ældre D074-punkt. Alle 900 minima, komplette SSE-kurver og koefficienter er identiske med det allerede afsluttede D075-resultat. Det er reproduktion på samme data, ikke nye observationer eller en ekstra fase.

Versionskontrollen fandt og bevarede det nyere D075–D076-checkpoint. D076 er også efterregnet på ny: 577.440 gridpunkter, alle 1.440 minima/retningpar, 1.740 øvrige pardifferencer og 1.440 tre-dato-kontroller består; alle 254 låste input er uændrede. De aktuelle 105.681 tabelceller og alle oprindelige kandidatværdier/fejlflag bevares.

Ved 0061 når ordens-/samleforskellen 1,45 km/s i D075. Ved referencebytning i D076 når den log-additive frem-/tilbagerest 0,95 km/s. Det er metodeafhængighed, ikke en valideret fysisk stjernehastighed. Ingen kvalificerede lasersignaler; alle tre oprindelser er fortsat uafklarede. Gridtrinnet 0,05 km/s er ikke hastighedspræcision.

Næste foreslåede trin er D077: metadata og proveniens for alle 30 allerede angivne WLC-kalibreringsreferencer. D077 er endnu ikke låst eller udført. Der er ingen nye FITS-sciencearrays, rå CCD-analyser, arkivhentninger eller baggrundsberegninger i denne fortsættelse.

GitHub-leverancen er afgrænset til tekst: status, metodeparametre, resultatsammendrag, auditreceipts og offentlige ESO-identiteter. Den komplette numeriske evidens ligger i projektets checkpoints. Den historiske pakke med 663 filer blev afvist af automatisk godkendelseskontrol, som vurderede den præcise offentlige deling af evidensarkiver som utilstrækkeligt godkendt. Den samme pakke er ikke genforsøgt ad en anden vej og er fortsat ikke publiceret.

De nye kontrolreceipts dokumenterer både reproduktionen og afstemningen med den nyere tilstand. Den fastholdte historiske baseline version 59 og det oprindelige D075–D076-resultatarkiv er uændrede. Den aktive pointer forbliver D076; genberegningens gamle næstehandling må ikke bruges til at gå baglæns.
