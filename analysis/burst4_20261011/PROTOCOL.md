# S2017 four-row burst pilot · 11 October 2026

This is a new temporal hypothesis family on exposed historical observations. It adds no observing visit, frequency coverage or blind replication. Original acquisition roles, failed A/B qualification and protected 2016 controls remain unchanged.

Three original OFF pointings (HIP97319, HIP97461, HIP97663) each search 96 metadata-selected cores: native 170/171/172 and q=4+8k, k=0…31. Each 4096-carrier map combines seven four-row windows starting at rows 0,2,4,6,8,10,12, 159 drift values spanning −4…+4 Hz/s and widths 1/3 channels. Four integration lengths are 73.014444032 seconds; their midpoint span is 54.760833024 seconds. This produces 288 combined maps, 1,179,648 carrier maxima and 2,625,896,448 correlated hypotheses. The unchanged 16-row robust preprocessing uses the whole declared normalization core once per map.

The reference frequency is defined at the first integration midpoint of the winning window. Absolute source-channel mapping is rounded before subtracting the crop origin. Strict greater updates preserve ascending window, width and drift tie order. Global ranking is performed once across all 96 combined maps of each target, by score descending then absolute channel ascending, with greedy carrier distance greater than three. No mask or geometric veto is applied. The uniform core selection excludes q128 by geometry; the observations were already exposed, so this does not constitute blind avoidance of known components.

Primary score audits retain raw 4×503 float32 capsules and the four full box contributions. Independent QA reconstructs each local 501-channel median and score, conditional on the saved whole-core residual location/MAD; it also independently verifies the raw whole-core power medians for all 16 rows. This saved-output QA does not rerun every search alternative or independently recompute every whole-core residual scale.

After primary QA, each target's first three saved winners is held fixed in all six chronological original scans. All 16 raw row boxes are saved. The four-row context score uses the same local row window and sqrt(4×width); the whole-scan context score separately uses sqrt(16×width). Actual scan epochs and gaps determine extrapolation. The 159-value drift grid is chosen for the four-row duration, so extrapolated context mismatch cannot demonstrate another direction's absence. HIP98505 has three original ON scans; the other three targets each have one OFF scan. These contexts are descriptive and are not additional repeats of the primary stars.

Code, metadata-only scope and QA are published and served bytes verified before root GO. Each primary job is create-only, CPU≤600 s, wall≤900 s, address space≤2 GiB, output≤50 MiB; at most two jobs run simultaneously. Failures are preserved without automatic retry. Telescope HTTP requests and cost remain zero. Empirical robust box-track maxima are not calibrated SNR or false-alarm probabilities and cannot themselves qualify a SETI detection.
