## Meaningful defects found in the reviewed snapshot

1. **Exhausted operating deadline loses failure evidence.** Network callbacks and terminal receipt/report writes share the same whole-scope deadline. A mocked acquisition crossing it preserves `spent.json` but fails to retain either raw transport/acquisition receipt or `supervisor-result.json`. This is reproduced without a connection in `reproduce_review.py`, `reproductions-01.log`, and `repro-deadline-artifacts`. Use an operating cutoff within the unchanged 300-second whole budget; retain time for receipt writes, after pins and manifest/report. The scope remains irreversibly spent.
2. **Trust callback undercounts conservative requested reads.** `trust_read` calls `held_file` without a charge callback, assuming the adapter's length-plus-one precharge covers every syscall request. Short reads violate that assumption: five pinned bytes returned through two-byte reads cause requests 5+3+1+1=10 against precharge 6. The callback also admits a size-one-bigger file and its extra EOF probe. Debit every requested trust read, reusing the prepaid allowance and charging any surplus before syscall. Retain actual received counters separately. Same pure reproduction log.
3. **Prospective installation storage law omits B evidence allowances.** The fixed output inventory and conservative evidence formula omit selected proxy/transport descriptor and three transport receipt caps. Include their finite caps and paths within original limits; do not increase resource ceilings.
4. **Detached proof parser permits duplicated repository paths.** `verify_publication` accepts all source rows mapped to one identical `repository_path` (`check_proof_paths.py`, `proof-paths-01.log`). This does not undermine a correctly authenticated caller readback, but add uniqueness sanity. Activation provenance and actual tree-path/blob association still require independent caller verification: the supervisor explicitly does not reauthenticate Git network provenance.

All four findings were sent to the implementer before freeze and corrected in snapshot-03 and confirmed in the final snapshot-04, which additionally guards the operating interval before spend and before native dispatch. The final complete supplied suite passes 136 tests under `-I -B -S` (`supplied-tests-04.log`). The exact accepted file bytes/hashes are retained in `accepted-source-pins.json`; no blocking code finding remains in that cohort. Independent fixed reproductions confirm the operation-cutoff failure returns `CLOSED_FAILED` with spent record, separate raw acquisition/transport receipts, full after-pins inventory, manifest and final result retained; trust requests totaling ten bytes are charged ten bytes while received bytes remain five; duplicate publication paths are refused. See `reproductions-fixed-03.log` and `proof-paths-fixed-03.log`. No live transport or runtime qualification follows from these synthetic checks.
