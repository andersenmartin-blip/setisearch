# Fixed typed metadata completion

This inert source family can fetch only the exact missing metadata fragments recorded by an actually closed, clean typed cache plan. It does not issue HEAD or re-fetch any initial prefix. It rejects an overall INVALID_METADATA or UNSUPPORTED_FORMAT plan and any invalid/unsupported source, even if such a plan contains proposals. Every current clean proposal enters the frozen request list in six-source/plan order; no amplitudes or scores inform selection. Actual offsets and lengths remain unset until that real plan exists.

The actual round scope pins the shared cache_admission module, original six-source manifest, initial transport/real exit0/full wait4 resources, prior complete rounds, parent planner scope/result/EXEC/code/parser, and any previously attempted intervals. A frozen initial V2 scope is joined through its real source_id_manifest_pin and initial scope/execution/header-result/source pins; no alias is added to that already frozen file. Later separately frozen round planners may provide an exact cache_admission object. Cached parent field bytes, SHA256, encoded hex and parent cache pins are checked before any HTTP. Fragments must lie in allowed bounded metadata objects, outside all retained prefixes/fragments and prior attempted intervals. Group symbol-table metadata is allowed; native raw-chunk index traversal and untyped live heap bodies are not.

The once-only round worker makes at most96 fixed GETs, with zero HEAD, redirects, retries or adaptive followups. Each GET uses the retained strong ETag in If-Match and requires exact206/URL/ETag/Content-Range/Content-Length/identity encoding before BODY reading. Every returned piece is counted immediately, then flushed to parent stdout as base64+SHA256 (at most1024 raw bytes), before local disk IO. HEAD identity is reused from the authenticated initial cache. All returned partial bytes and receipt observations are retained without replay. The first failed request stops the remaining fixed list; uncalled requests stay uncalled and the full root reservation remains charged.

Round limits are20 combined launcher+child CPU seconds,300 wall seconds,512MiB per process,32MiB output,12GiB shared workspace and an actual frozen fragment sum no larger than1MiB. Child stdout is bounded to4MiB and stderr65.536B. Root must capture tool output in short yielding chunks and retain the complete live stream, without exposing raw base64 in conversation. Root saves actual fragment bytes/metadata durably immediately after close. An outer meter starts only the pinned child, relays stdout before local log IO and uses wait4 through interpreter close. Resource PASS is separate from the original worker status and real exit. Downstream cache admission requires complete inner status plus actual outer exit0, matching original receipt pins and resource PASS.

No source values, h5py/NumPy, scientific codec, score, band selection or header geometry interpretation is used here. Spectral access, native acquisition and independent validation stay BLOCKED_PROTECTED_REGISTRY_UNRESOLVED/BLOCKED. A completion transport success establishes provenance of retained metadata bytes only.

Root first writes a JSON config containing round_id, exact cache_admission, planner_scope/result/execution/worker/parser pins, owner_binding_pin and prior_attempted_request_pins. prepare_scope.py reads only bounded UTF8 JSON/code; it never imports workers/parser/cache modules or opens prefix/fragment binaries. It writes one create-only tools/.../scopes/round_NN.json. That actual scope is separately published/read back before root late admission and network GO. Root admission lives at results/.../round_NN_ROOT_ADMISSION.json and pins the scope/code/sourcefreeze, source-only peer, no-refund actual fragment BODY reservation and finite ownership/request checks. It is deliberately supplied by CLI SHA after scope freeze to avoid a scope/admission circular hash.

Commands use absolute paths and exact real pins:

```sh
python /absolute/repo/tools/radio_visit2019_typed_completion_20261010/prepare_scope.py --config /absolute/repo/actual_config.json --expected-config-sha256 CONFIG_SHA --root-go-source-only-scope
python /absolute/repo/tools/radio_visit2019_typed_completion_20261010/launch_once.py --scope /absolute/repo/tools/radio_visit2019_typed_completion_20261010/scopes/round_01.json --expected-launcher-sha256 LAUNCHER_SHA --expected-wrapper-sha256 WORKER_SHA --expected-scope-sha256 SCOPE_SHA --public-freeze-commit SCOPE_COMMIT --launcher-public-freeze-commit SOURCE_COMMIT --expected-root-admission-sha256 ADMISSION_SHA --root-go-typed-metadata-only
```

No actual scope, production cache read, HTTP, parser or worker execution has occurred during source preparation. Existing initial/header/failed-plan histories remain unchanged. No old lost BLC66 prefix or HEAD can be replayed.
