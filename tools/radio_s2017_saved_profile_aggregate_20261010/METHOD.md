# Saved S2017 profile aggregation

This new finite, posthoc analysis uses only OUR authenticated saved 2017 profile arrays. It follows the existing selection of 635 matched triples and all three original member hypotheses per triple, giving 1,905 member paths. It does not select new source cells. The six scans remain in the order epoch1_on, epoch1_off, epoch2_on, epoch2_off, epoch3_on, epoch3_off. Each member retains its own original ON reference time, frequency, drift and width.

The input contains 11,430 logical scan profiles referring to 11,369 unique saved geometries. The 61 aliases reuse existing geometry statistics. The earlier exclusion of 54 cases /312 distinct geometries and zero old overlap remains a provenance condition. It is not an independence claim.

For each unique saved geometry, the producer uses the 16 already stored normalized-center-minus-local-flank residuals. It computes the equal-weight mean of all 16 rows, the means of rows 0..7 and8..15, strict positive-row count, mean>0, both half means>0 and all16 rows>0. It never recomputes a profile median, full-native median, normalization, raw patch, codec or detector. No rows are concatenated across scan times or fitted to a consensus track. These positive-value predicates are descriptive signs, not thresholds for candidate admission.

For each of the1,905 member paths, the signed worst-mean gap is min(the three ON means) minus max(the three OFF means). The signed worst-half gap is min(the six ON half means) minus max(the six OFF half means). Negative, zero and positive values are all retained.

For each unique OFF geometry, a second diagnostic uses its already saved129-point mean-normalized-minus-flank frequency profile at offsets-64..64. With the unchanged member width1 or3, it averages every fully supported window of that width. It records the largest window mean and its center offset. Ties in the producer's binary64 window values choose the lowest native channel offset. Width3 permits centers-63..63; width1 permits-64..64. This is a saved-neighborhood diagnostic, not refitting or extracting a new track. The signed neighborhood gap is min(the three ON center-profile means) minus max(the three OFF local-window means).

The producer stores two complete descriptive orders: signed worst-mean gap descending and signed neighborhood gap descending, breaking ties by logical_member_index ascending. It exports all1,905 records and all635 parent triples. Triple records report counts among their three fixed members; they do not combine independent observations. The display case is the first member in the mean-gap order. Its six original129-point curves are exported unchanged for plotting. Original robust detector scores remain identity/provenance fields and are never compared with normalized profile means or used in either new rank.

Outputs are SAVED_PROFILE_AGGREGATE.json, MEMBER_METRICS.csv and GEOMETRY_AGGREGATE.npz, plus input and terminal receipts. The JSON includes complete records, all635 triple counts, both full rank permutations and the display case. The NPZ stores compact per-geometry statistics; OFF local-window fields are meaningful only for OFF scan indices. The CSV includes every member, with no amplitude-based filter.

Runtime is one shot, with a durable create-only AGGREGATE_STARTED_ONCE.json and process-owned AGGREGATE_SERIAL.flock held through terminal publication. Input bytes, the original COMPLETE/QA/closed outer receipts, source code/scope and the new code/scope are checked before lazy NumPy import and rechecked at completion. Historical QA metadata is read only; its OTHER source paths are not followed. There is no HTTP, HDF5, source decode, nearest matching or original detector invocation. Limits:120 CPU seconds (hard122),600 wall seconds,1GiB address/RSS bound,32MiB output,12GiB total declared shared scratch. Terminal publication has1MiB reserved headroom. Root must freeze/read back the filled scope and source before the one actual invocation, then measure full command closure independently.

These are new descriptive aggregations of already inspected, same-visit selected data. They provide no calibrated SNR, false-alarm probability, random null, independent validation, OFF veto, candidate qualification, sensitivity or source-origin classification. A positive center gap or neighborhood gap cannot establish absence elsewhere in OFF observations. Original resource failures, source-file MD5 limitations and protected-data statuses are preserved. New original detector hypothesis combinations:0.
