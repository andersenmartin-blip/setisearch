# Author repository provenance

Primary source: https://github.com/PetchMa/ML_GBT_SETI/blob/5f9c006a2960683969d9face28119af4d5b410b5/README.md

Original Git blob: `ff05ac39ce9acf3d29cc8597274f8ac40c4a89bd`.

The repository documents the Ma et al. machine-learning SETI project, model/training code and the author-released eight-candidate dataset. Its background training observations and general survey inputs are linked to the external Breakthrough Listen archive. Training and candidate observations of the same target can come from different epochs. The repository also records a later correction to simulated drift-direction sampling. No model training, external archive retrieval or TOP8 power analysis was performed here.
