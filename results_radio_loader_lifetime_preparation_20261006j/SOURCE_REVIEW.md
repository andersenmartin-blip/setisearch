# J source inspection and limits

This is a second source inspection by the same working agent, not an external
review, independent live observer or qualified full-lifetime result. No subagent
or person was contacted.

The component reads no files, starts no process and imports only hashlib, json
and pathlib. An externally supplied stream, identity and file expectations are
canonical-copied. It validates exact types and schemas, raw-body chain,
nondecreasing timestamps and one fixed process identity. All object generations
remain in the ledger when closed. The actual open/close event timestamps are
retained, including transient objects absent at the terminal endpoint. Both
expectations and emitted receipts use defensive copies.

Every failed consume poisons the stream. Attempted raw bytes are charged even
when the body is truncated, malformed or over its bound. Event, byte and object
generation caps are finite. No resumption, implicit startup, namespace guessing,
silent path normalization or implicit terminal success exists. This is a bounded
in-memory reducer of caller-provided bytes, not a streaming collector or a
guarantee that an external caller stayed within its own memory/IO envelope.

The full and omitted/rehashed fixtures both correctly retain false authentication
and coverage/authority fields. A source chain cannot authenticate its producer,
independently attribute a descriptor, observe missed events, stop inode races,
verify symbol binding, cover manual executable memory or qualify terminal IO.
The deliberate missing support for kernel pseudo-objects and new namespaces
means this component cannot directly accept a real generic Linux loader log.
None of those refusals may be relaxed merely to make a failed actual control pass.

The administrative evidence builder reads 11 exact Git context bodies from the
specified I authority, with no execution of those bodies. It reads only four
named administrative/runtime-boundary paths, up to 64 MiB each, hashes present
ordinary resolved files, and checks held/named/symlink identity stability. It
records the absent canonical G executable without substitution. Existing system
binary presence supplies no trace-access or installed-scientific-cohort claim.
It constructs one labelled artificial fixture by importing the stdlib-only test
definitions; it does not run a kernel collector or the test suite again.

All 27 tests in the final cohort pass. The earlier 26-test attempt is retained;
the final cohort adds the explicit rehashed-omission limitation and renames the
identity test to match the checked PID/namespace/start-time fields. Neither
attempt is a scientific trial, native codec control or evidence of recovery/RFI
performance. I's 43-test result and preflight are preserved without rerunning
unchanged tests. No marker, allocation, installed runtime, telescope value,
codec certificate or complete-loader claim exists. H remains unchanged.
