This continuation adds a bounded, inert `loader_lifetime.py` reducer for a
proposed normalized loader-event stream. It preserves transient object
generations after unload and refuses incomplete, substituted and resumed streams.
It is **SOURCE_COMPONENT_NO_COLLECTOR_NO_DISPATCH**. All runtime, continuous
custody, collector authentication, codec certificate and execution flags remain
false, even for valid fixtures. There is no actual observer, native trace,
controlled codec, allocation, runtime installation or telescope analysis.

The [protocol](PROTOCOL.md) gives exact bounds and limitations. In particular,
hash chaining cannot authenticate a collector or prove absence of omitted events.
The tests deliberately rehash an omitted load/unload pair and verify that the
result still grants no authority. The former G runtime's missing canonical path
is retained in `CURRENT_RUNTIME_BOUNDARY.json`; administrative file presence
does not imply callable tracing or a current installed target cohort.

`FIXTURE.events.jsonl` and `FIXTURE.receipt.json` are manufactured source-test
data, not process/kernel observations. `/fixture/*` names and their supplied
file pins are invented test inputs; they are not runtime files. No fixture
process identity is a current live identity. The isolated stdlib tests cover
retention, generation reuse, process/start-time/namespace substitution, path and
pin mutations, startup order, loss/exit declarations, exact types, truncation,
budgets and no-authority behavior. Every attempt's stdout/stderr is retained.
