# M43V: matched component ablations and failure-stage evidence

This is a retrospective diagnostic motivated by the completed M43U failures,
not independent validation. No detector, threshold, mask, association or veto
rule changes. Preserve M43U and both M43T histories.

Use all eight M43U mixed cases plus the two leaking controls, cases 61 and 69.
For every selected two-component input execute, in this fixed order: both
components, first alone, second alone. Keep native positions, strength, shape,
epoch membership and addition order exactly as M43U. The same three policies
give 30 native inputs and 90 detector executions: 30 exact historical endpoint
replays and 60 new component-ablation endpoints. Three uninjected executions
are separate baseline replays. No new observations or held-out nulls.

Reconstruct each original M43U calibration on its original 128 shifts and
require exact maxima, summary, threshold and binding equality. Revalidate all
96 arrays and 48 native ON/OFF gather anchors. Every both-component audit and
baseline audit must equal its original compact M43U audit, including the full
pipeline digest. Abort on mismatch or any inherited cap/coverage failure.

Retain complete compact member decisions for all 90 endpoints. For each of
the four distinct historical leaking-control member coordinates, record ON/OFF
scores, masks, isolation seeds and same-width neighboring support, plus all
available retained OFF, paired-OFF, receiver-signature, alias and rank evidence
for that coordinate under both and each component alone. Probe coordinates
are fixed from the published M43U ledger before these executions.

Compare final-member coordinate sets (template, carrier, width, exact active
epoch subset), rather than score-dependent record IDs. Report both-only,
shared and removed coordinates relative to the union of the two components
alone. These are conditional responses to controlled interventions in one
background; neither independent events nor causal source identifications.
In mixed inputs also report recovery of the intended combined-profile truth
for both, signal-only and interferer-only. An association under interferer-only
is a diagnostic confusion, never recovery of an injected true signal.

The input-component union need not equal the output-member union: masks,
thresholds, activity cuts and vetoes are nonlinear. Do not label all unassociated
members interference, invent a pass gate or tune a correction on this panel.
Any proposed rule requires a later prospective freeze and new evaluation
combinations. This milestone ends with the causal-stage diagnosis and a concrete
next test, while general adoption and astronomical candidates remain unqualified.

The legacy disposition string `pending_receiver_alias_evaluation` must be
interpreted from the executed alias evidence: the routine can leave this label
after evaluating aliases and finding no rejecting match. Report actual executed
stages rather than inferring missing execution from the string alone.

Code, configuration, focused analysis-helper tests and this plan are published
before the 90 endpoints. Per-input sealed restart files must match the freeze,
configuration and selected input. A complete result requires all 90 endpoints.
