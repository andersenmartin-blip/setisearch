# M43O — public checkpoint schedule blocked by approval review

The M43O protocol and implementation were public before numerical evaluation,
in commit f69a431629ebdd66a3bcf6b0b019d5779952062b.

During the run, the first three complete OFF products (widths 33, 65, 129)
were locally committed as 27246b3. The GitHub tree-creation request was rejected
by automatic approval review because the latest explicit user approval covered
M43N, while the continued project request did not specifically authorize public
disclosure of the new M43O telescope-derived stack checkpoints and provenance.

No workaround or alternate publication channel was used. The numerical run
continued locally under the already authorized analysis scope. All batches
remained atomically checkpointed and complete products remained auditable.
Public upload was deferred pending explicit approval of the completed package.
No completed M43O checkpoint was public during evaluation. This is a disclosed
deviation from the planned during-run public checkpoint schedule; the numerical
rules, sources, oracle, scope and success criteria remained frozen and unchanged.
