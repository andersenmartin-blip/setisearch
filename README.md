# SETIsearch — Reproducerbar arkivbaseret teknosignaturforskning

*English summary: Open, prospectively locked archival technosignature research by Martin Andersen (MSc Astrophysics, University of Copenhagen), spanning **13.919 unbroken spectral octaves (`0.0905–1,401.36089 µm`)** plus **ALMA Bands 5/4/3/1 (`35.037–210.905 GHz`)** closing the prior `1.40–3.44 mm` gap up to terrestrial $\mathrm{O_2}$ (`118.75 & 60 GHz`) opacity walls and reaching **`8,556.41831 µm` (`16.529` total octaves)** across **ALMA**, **JCMT** (`'Alaihi 3 mm` & `HARP/RxA3/Uu`), **Herschel** (`HIFI`, `SPIRE FTS`, `PACS`), **SOFIA** (`FIFI-LS`, `GREAT`, `EXES`, `FORCAST`), **ISO/SWS**, **JWST** (`NIRISS/SOSS`, `NIRSpec`, `MIRI LRS/MRS`), `Spitzer IRS`, **IRTF SpeX**, space UV (**FUSE**, **IUE `SWP/LWP`**, `HST/COS`, `HST/STIS E140H/E140M/NUV`), simultaneous 3-arm `VLT X-shooter`, `MPG/ESO FEROS`, `ESO HARPS`, `FLAMES/GIRAFFE HR`, `Gemini GHOST/GRACES`, `CORALIE`, `UVES`, `ESPRESSO`, `HARPS-N`, `OHP SOPHIE/ELODIE`, `CFHT ESPaDOnS`, `CARMENES_VIS`, `NIRPS_HE`, `SDSS APOGEE-2`, `CRIRES+`, `CFHT SPIRou`, `1.4 GHz` Parkes/GBT radio (`seti-repeater`), and `TESS` photometry. Advancing through **Phase D101 (`V5.9`: `TECHNOSIGNATURE_V5_9_ALMA_MM_BAND1_GAP_CLOSURE_AND_COHERENT_DRIFTING_COMB`)** across twenty-three phases (**`D079–D101`**), the unified survey unites **613 unique analyzed stellar/extragalactic systems** (`472` science [`226` hosts / `429` planets] + `141` controls), **`2,977` exposures (`1,227.5768 h`)**, **`41` spectrographs (`67` spectral arms)**, **`76` multi-phase science bridges (`79` multi-regime / `873` cells; `83` multi-phase targets)**, **`180` `< 10 pc` stars (`1.4488 kW` median limit)**, **`48,726` calibration trials** (`2,264/2,271` in `D101`), **`156` orbital campaigns**, `479` uniform all-sky `COMB_V4_1` stacks (`4,919,788` `D101` configs -> `1,033 -> 0`), `48`-campaign **`COMB_DRIFT_V59`** + `DRIFT_V59`, and **100% (`23/23`) Parkes/GBT `1.4 GHz` radio-echelle closure (`24` direct overlaps)** ([`paper/ANDERSEN_2026_PANCHROMATIC_ECHELLE_SETI_SURVEY.pdf`](paper/ANDERSEN_2026_PANCHROMATIC_ECHELLE_SETI_SURVEY.pdf) · [`paper/ANDERSEN_2026_PANCHROMATIC_ECHELLE_SETI_SURVEY.md`](paper/ANDERSEN_2026_PANCHROMATIC_ECHELLE_SETI_SURVEY.md) · [`paper/main.tex`](paper/main.tex)) — `ALMA Band 1/3/4/5` (`62` cubes / `58` targets -> `240/240` cal; `22 -> 3 -> 0 ETI`, `8,556.41831 µm` frontier on `CIRCINUSGAL spw25`, **`186.9983 kW` `AU Mic B3`**), `ESO ESPRESSO + HARPS` (`39` exposures / `9` stars, `#151–#156 -> 0 ETI`, **`0.3550 kW` `GL 479 HARPS`**, **`8.1103 kW` `HIP 56998 ESPRESSO`**), and **`COMB_DRIFT_V59`** (`240/240` cal vs. `11/120` static `V4.1`; `8,277` comb-drift traj. `3,048 -> 166 -> 0` + `63,809` drift traj. / `6,088,120,032` px-int `14,176 -> 0`) establish **0 verified technosignature detections** across all **`613` targets (`805,073` V2 false alarms eliminated; `16/16 PASS` pure-stdlib audit; `31/31` data + `6/6` figures bit-identical; Companion Archives `A–Z, AA`)**.*
