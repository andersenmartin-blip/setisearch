# Independent source review of the I integration

This is a separate source inspection, not a live native result or an external
reviewer's approval. No subagent or external person was contacted.

The immutable H raw pins authenticate all four inputs before decoding the plan.
Every original body is checked against both SHA-256 and Git blob SHA-1, and the
complete 632,453-byte/14-file total is checked. Selected normalizer AST segments
retain their exact original line bytes and SHA-256. Helpers compile authenticated
memory, avoiding a second unverified disk import. The isolated preflight confirms
both maintained receiver contexts. It does not compile the normalizer selections
or import NumPy/h5py/hdf5plugin.

The producer is closed at the public entry and CLI. The private future leaf body
re-authenticates source inputs itself; it accepts no caller-authored plan,
normalized arrays or row hashes. Its output exclusion covers the entire same
canonical repository root. Native imports occur only in that uninvoked body.
Outer runtime/activation authority is deliberately not implemented or asserted.

The chunk reader inspects size, mask and expected retained length before calling
the payload reader. It rejects zero/over-cap/boolean lengths, nonzero/boolean
masks, short bodies and differing retained hashes. The current encoder signature
is fixed to the closed G observation `[32008,1,[0,4,4,0,2]]`; the legacy declaration
remains the independent source signature `[32008,1,[0,3,4,0,2]]`. Current-runtime
version equality is necessary but does not establish runtime qualification.

The write path uses exclusive single-link files, flush/fsync and directory fsync.
The journal's sequence and predecessor hash are verified canonically, including
boolean rejection. Journal caps are checked before a write. A failed partial
write leaves its original bytes and makes a second-use refusal observable. The
success verifier requires all 602 phases in the exact handoff and row order,
per-handoff receipt hashes and the final result hash. Outer immutable rehash and
continuous storage/RSS/loader observations remain required; the producer's
snapshots do not claim those lifetime properties.

The first 30-test cohort and subsequent 43-test cohort passed. Original logs are
retained, with the final source test result recorded separately after review.
Metadata stubs in tests have an explicit test domain and describe no actual HDF5
payload. Normalized hash repetition is tested as permissible because centering
can erase additive salt; no scientific freshness is inferred from it.

Two review hardenings are included: the private body now reloads fixed raw inputs
instead of accepting mutable dictionaries, and failure-receipt persistence errors
become explicit exception notes. Complete typed row/file receipts, pre-allocation
chunk vetoes, exact success phase verification and full-root output exclusion
also have source regression coverage. No failed live evaluation was retuned.

Disposition: **source integration checked; live outer/native-lifetime admission
remains missing**. Preserve the original preparation-only contract and all
closed/spent scopes. Integrate authentic current runtime/lifetime inputs before a
distinct executable freeze; do not activate this source freeze.
